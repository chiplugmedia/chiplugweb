# Chi Plug Media - Vite + React + Tailwind CSS Redesign

This repository contains the full modular codebase generated for **Chi Plug Media**.

## 🚀 Quick Start Instructions

1. Extract the ZIP file to your workspace folder.
2. Open terminal in the extracted directory.
3. Install dependencies:
   npm install
4. Start development server:
   npm run dev
5. Open your browser at `http://localhost:3000`.

## 📦 Available Scripts

- `npm run dev` - Launches local Vite server with instant HMR.
- `npm run build` - Compiles production-ready bundle to `dist/`.
- `npm run preview` - Locally previews production build.
